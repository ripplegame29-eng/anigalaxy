# Промо-ролик AniGalaxy

1. Запустите сайт: `npm run dev` (localhost:3000), откройте любую страницу и дождитесь загрузки.
2. В другом терминале, из корня проекта:
   ```
   npm i --no-save playwright-core
   node promo/capture.mjs
   ```
   Нужен установленный Google Chrome или Edge. Съёмка идёт в гостевом режиме (личных данных нет), занимает около 5–7 минут. Окно браузера не открывается.
3. Кадры появятся в `promo/raw/<сцена>/`. Дальше монтаж.

Выборочно: `node promo/capture.mjs d03 m01` — только сцены, имена которых начинаются с этих префиксов.
