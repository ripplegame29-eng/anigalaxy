# Ролики главной страницы

Пять mp4 лежат здесь, но **в git не попадают**: вместе они весят ~37 МБ (облегчённые копии, оригиналы лежат в video-originals),
и каждый клон качал бы их заново.

Файлы нужны для секции «Главная» (`src/app/page.tsx` → `HeroSlider`).
Без них сайт работает, только слайдер показывает статичные постеры.

## Что делать после клона

1. Положить ролики в эту папку:

   | файл | размер |
   |---|---|
   | `rezero.mp4` | ~7–8 МБ |
   | `jujutsu-kaisen.mp4` | ~7–8 МБ |
   | `bleach.mp4` | ~7–8 МБ |
   | `gachiakuta.mp4` | ~7–8 МБ |
   | `solo-leveling.mp4` | ~7–8 МБ |

2. Убедиться, что имя совпадает: подключение идёт по пути,
   другое имя — слайдер просто не найдёт ролик и покажет постер.

Имена файлов заданы в `src/app/page.tsx`, там же у каждого — тайтл
и постер-заглушка.
